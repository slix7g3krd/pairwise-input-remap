# pairwise-input-remap

手柄热插拔后，攻击键变成了菜单键，映射表按设备索引存，新设备占了原来的槽位；键位按物理按键编号绑定，换布局后 A/B 互换；重映射时没有冲突检测，两个动作绑到同一个键；键鼠和手柄同时在线，最后输入设备判定错，提示图标乱跳；长按和连点共用同一个动作，长按触发时连点也触发；组合键优先级按注册顺序，后注册的覆盖了系统快捷键；摇杆死区写死 0.2，漂移手柄一直往一个方向走；重映射配置只存在内存，重启后回到默认；提示图标没有跟着映射变，屏幕上显示的还是旧键位；切换设备时输入缓冲没清空，旧设备的按下事件在新设备上触发。gameplay/input_remap.py 是核心，tests/test_input_remap.py 15个红。要修的是：按设备 GUID；按动作绑定；冲突检测；最后输入设备；长按计时；组合优先级；死区校准；持久化；图标随映射；切换清缓冲。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
